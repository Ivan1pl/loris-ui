## Project Documentation

Located in `.maister/docs/project/`

### Vision (`project/vision.md`)
What LorisUI is (a declarative, toolkit-agnostic Java UI library for game menus/HUDs rendered through a pluggable backend whose port is a single toolkit-neutral `render` call, currently Dear ImGui on OpenGL 3, OpenGL ES 3, SDL_GPU or Vulkan, hosted in jMonkeyEngine 3 (its default ANGLE renderer or OpenGL) or an application's own LWJGL loop with SDL3 or GLFW), the problem it solves, target users, key features (custom components/styles registered on the backend or a host display, `ImGuiJmeDisplay` with automatic OpenGL ES 3 / OpenGL 3 selection and the four LWJGL displays `ImGuiLwjglSdlGl3Display`/`ImGuiLwjglGlfwGl3Display`/`ImGuiLwjglSdlGpuDisplay`/`ImGuiLwjglSdlVulkanDisplay` with input routing, `ScreenManager` lifecycle hooks, re-attach and safe in-frame teardown), success criteria, differentiators, and firm constraints (dependency-free `loris-ui-api` / `lorisui.api`, latest Java LTS only, solo-developer-scale process).

## Technical Standards

### Global Standards

Located in `.maister/docs/standards/global/`

#### Coding Style (`standards/global/coding-style.md`)
Consistent naming conventions, automated style checks (Checkstyle build gate plus `.editorconfig`, no auto-formatter), descriptive names, small focused functions, space-only 4-space indentation, removal of dead code (unused imports rejected by Checkstyle), no backward-compatibility shims unless required, and DRY (extract repeated logic).

#### Commenting (`standards/global/commenting.md`)
Let code be self-documenting, comment sparingly (explain "why", not "what"), never leave change/history comments in code, and require user-facing Javadoc on exported public API and `jme3` (contract, null semantics, threading; no implementation details; summary sentence, full `@param`/`@return`/`@throws`; `package-info.java` per exported package, module doc comments, American spelling; none needed for `impl`/private code or the public types of qualified-exported helper packages, which still get a `package-info.java` and a module doc comment), with shared phrasings for required arguments, optional constant overloads, Supplier getters and resource paths.

#### Conventions (`standards/global/conventions.md`)
Predictable project structure, up-to-date documentation, clean version control (clear commits, focused branches), environment variables for config/secrets, minimal dependencies, consistent code reviews, testing expectations, feature flags for incomplete work, changelog updates, building only what is needed, lightweight process for a solo maintainer (e.g. a single `./gradlew build` CI job), and never committing build or IDE outputs (`build/`, `.gradle`, `.idea/`, `*.iml`, etc.).

#### Error Handling (`standards/global/error-handling.md`)
Clear user-facing error messages, fail fast on invalid state, typed/specific exceptions, centralized error handling at boundaries, graceful degradation, retry with exponential backoff for transient failures, and guaranteed resource cleanup.

#### Minimal Implementation (`standards/global/minimal-implementation.md`)
Build only what is needed now, every piece of code has a clear purpose, delete exploration artifacts, no stubs for future features, no speculative abstractions, review diffs before commit, and treat unused code as debt.

#### Validation (`standards/global/validation.md`)
Always validate server-side, client-side validation only for feedback, validate early at boundaries, specific error messages, allowlists over blocklists, type and format checks, input sanitization, business-rule validation, and consistent enforcement across entry points.

### Architecture Standards

Located in `.maister/docs/standards/architecture/`

#### Modules (`standards/architecture/modules.md`)
Strict layered module chain (`examples` → `loris-ui-jme3` / `loris-ui-lwjgl` → `loris-ui-imgui` → `loris-ui-api`; below `loris-ui-imgui` the internal helper modules `loris-ui-imgui-vulkan` (→ `api`) and `loris-ui-imgui-gles3`, split off only for their MIT license) with a zero-dependency, drawing-free `loris-ui-api` that holds the host-support helpers (`ScreenManager`, `DeferredRelease`, `ResourceBundleKeyResolver`) in exported packages because the automatic `lorisui.jme3` reads only exported packages; new backends depend only on `api`, new hosts only on `imgui`; packages `com.ivan1pl.lorisui.<module>.<area>` with `impl` subpackages (a helper module: one package `<module>.<part>`); JPMS names `lorisui.<module>` (helpers `lorisui.<module>.<part>`) without `.main`, `requires transitive` for siblings in exported signatures, plain `requires` for internal toolkits (`org.lwjgl.sdl` in `lorisui.imgui`, `org.lwjgl.glfw`/`org.lwjgl.sdl` in `lorisui.lwjgl`) and helper modules (`lorisui.imgui.gles3`/`lorisui.imgui.vulkan`), helpers exporting their package only to the module they serve under `@SuppressWarnings("module")`, and the plain `requires static` exception for optional, application-supplied toolkit modules used by one variant (`org.lwjgl.opengles`/`org.lwjgl.vulkan` in `lorisui.imgui`, the matching one in each port module, `org.lwjgl.vulkan` in `lorisui.lwjgl`; never `transitive`, LWJGL's `org.lwjgl.sdl` precedent, not resolved at runtime on their own, so applications in which the variant runs `requires` them or use `--add-modules` (jME on ANGLE: `org.lwjgl.opengles`), accepted `-Xlint:exports` warning, classes loaded only when the variant is used); `Automatic-Module-Name` for `jme3`; `impl` never exported, the helpers' qualified exports the only exception; host-internal shared logic may be package-private in the exported package (`ImGuiLwjglDisplayBase`, `ImGuiLwjglSdlInput`).

#### Component Model (`standards/architecture/component-model.md`)
Empty marker interfaces (`Component`, `Style`, `Font`) downcast by backends; toolkit-neutral `Backend` port (`render` only) with per-backend textures through `RendererProvider` (`renderTexture(long id, ...)`) and `unloadTextures()`, four final backends (OpenGL, OpenGL ES, SDL_GPU, Vulkan); input-capture queries (`wantsMouseInput`, `wantsKeyboardInput`, `wantsTextInput`, `isHoveringScrollablePanel`) on `ImGuiRenderer`; hosts pass the platform's logical window size (`SDL_GetWindowSize` / `glfwGetWindowSize`, Windows/X11 GLFW note) to the renderer variant's `render` every frame (never camera/viewport/`reshape`/framebuffer pixels), named for the jME display and all four LWJGL displays (Vulkan: target 0 while the swapchain is smaller than the window's pixel size); every host provides an sRGB framebuffer (`GL_FRAMEBUFFER_SRGB`, jME gamma correction for both jME renderers incl. GLES `GL_SRGB8_ALPHA8`, `SDR_LINEAR` swapchain, an sRGB Vulkan swapchain format for `R8G8B8A8_SRGB` textures); fonts registered on the renderer as `ImGuiFont`; class-keyed `Renderer`/`StyleApplier` registry with final superclass-chain lookup and fail-fast `IllegalStateException`; checklist for built-in components/styles; custom ones via `registerRenderer`/`registerStyleApplier` on the backend or any of the five displays; a custom `ImGuiBackend` pairs only with the GL3 or GLES3 renderers, a new graphics API needs a new sealed `ImGuiRenderer` variant, and each bundled display uses its own backend (jME chooses the GL or GLES one).

### Java Standards

Located in `.maister/docs/standards/java/`

#### Language (`standards/java/language.md`)
Target the latest Java LTS only (Java 25); sealed abstract classes with static factories and nested final variants; a sealed hierarchy of top-level classes in one package (`ImGuiRenderer`, `permits` five variants) with a package-private constructor and package-private hooks; exhaustive pattern `switch` without `default`; `instanceof` patterns over casts; records only for behaviour-free data carriers (`TextureData` in `imgui.backend`, `ComboBox.Item`); unnamed `_` for ignored parameters; explicit local types with sparing `var`; loops over streams in library code.

#### Naming (`standards/java/naming.md`)
PascalCase types with role suffixes (`<Component>Style`, `<Component>Renderer`, `<Style>Applier`), `ImGui` prefix for toolkit-specific classes, camel-cased acronyms in type names (`OpenGl`, `OpenGlEs`, `Jme`, `Gl3`, `Gles3`, `Lwjgl`, `Glfw`, `SdlGpu`, `SdlVulkan`, as in `ImGuiLwjglSdlGl3Display`, `ImGuiSdlGles3Renderer`, `ImGuiOpenGlEsBackend` and `ImGuiLwjglSdlVulkanDisplay`; checked by Checkstyle), platform before graphics API in variant names; full-word generic type parameters ending in `Type` (`ComponentType`, `StyleType`, `IntBiFunction<ResultType>`, `RendererType`), enforced by Checkstyle.

#### Formatting (`standards/java/formatting.md`)
Style enforced by the Checkstyle gate and `.editorconfig` (no auto-formatter); 4-space indentation, K&R braces, 120-column limit, 8-space continuation, aligned wrapped parameters, one fluent call per line, inline `{}` empty constructors; IntelliJ import layout (project/third-party block, blank line, `java.*`) sorted in case-sensitive ASCII order, no static imports, wildcard imports acceptable; member ordering from constants to nested `Builder` last.

#### Class Design (`standards/java/class-design.md`)
Private (mostly final) fields with JavaBean getters, mutable state limited to runtime UI state, unmodifiable wrapping of incoming collections; `@Override` on every override, narrowest-scope `@SuppressWarnings("unchecked")`, `@SafeVarargs` on final varargs builder methods.

#### Error Handling (`standards/java/error-handling.md`)
`IllegalStateException` for programming/lifecycle errors (before any state change), `IllegalArgumentException` for malformed arguments such as glyph ranges, `0` native handles and mismatched objects (constructors whose objects can't exist in tests check primitives first), checked `IOException` with resource path, `RuntimeException` wrapping where checked exceptions can't propagate, balanced push/pop in `try/finally`, no custom exceptions; per-frame object arguments checked `null` → `NullPointerException`, then another device → `IllegalArgumentException`, before the receiver's state checks, with a delegating host running its own state checks first and not repeating them; native result-code failures as `IllegalStateException` naming function, code and object, built in one helper per API from a caller label (Vulkan details in `architecture.md`); multi-step teardown with `DeferredRelease.runAll`/`runAfterFailure` (every step runs, first failure propagates, later ones suppressed, never self-suppressed, null steps rejected up front; release only what was set up, with fresh Impl objects kept only after a successful init, except a failed `ImGuiImplSdlGpu3`, `ImGuiImplGles3` or `ImGuiImplVulkan` init shut down on the spot); deferred host teardown with `DeferredRelease.run`/`request`/`isPending` plus `ScreenManager.beginDeactivation()` (switches while pending only record), and suppressed draws when a host whose frame is submitted later is closed during the frame (frame state restored after a rejected nested `render`; Vulkan protocol in `architecture.md`); GLFW host rules (`close()` rejected inside the display's GLFW callbacks; dispatch failures caught and rethrown from the next `render()`/`close()`); unified null convention (optional `Supplier` properties default to `() -> null`, `requireNonNull` setters, null-accepting constant overloads, eager validation, required bindings checked in `build()`) and builder Javadoc rules; no nullability annotations or `Optional` fields.

### Components Standards

Located in `.maister/docs/standards/components/`

#### Builders (`standards/components/builders.md`)
Nested static `Builder` per Component/Style with private constructors, static `builder()` / `*Builder(id)` factories, prefix-free fluent setters and terminal `build()`; package-private self-typed `Panel.BaseBuilder<PanelType, BuilderType>` (with package-private `doBuild(...)`/`PanelFactory`) closing the Panel family to `api.component`; dynamic properties stored as `Supplier` / `IntBinaryOperator` / `Function<BundleKeyResolver, String>` / `Consumer` with constant overloads delegating to functional ones (e.g. ProgressBar `rounding` as `Supplier<Float>` defaulting to `() -> null`).

#### Renderers and Styles (`standards/components/renderers-and-styles.md`)
Renderer shape (`<Component>Renderer extends Renderer<...>` in `imgui.renderer.impl` with a no-argument constructor and no backend reference, child rendering via `RendererProvider`, `FLAGS_*` constants, component-derived ImGui IDs, font wrapping with `ImGuiFont.useFont` from the `imgui` package, balanced push/pop, textures through `rendererProvider.loadTexture`/`renderTexture` with opaque per-backend `long` IDs (GL or GLES texture name, `SDL_GPUTexture*` or `VkDescriptorSet`; per-backend cache, normalized keys, no unloading while drawing; Repeat tiled by the backend, no wrap-mode dependency), internal `imgui.impl.ImGuiState`, input-capture queries on `ImGuiRenderer`); class-loader resource lookup (`ClassPathResources`, used by `DecodedImage` for all four texture backends, leading `/` optional, `IOException` with path); Style class shape (`Supplier` attributes defaulting to `() -> null`, nullable unwrapped getters, constant overloads); `StyleApplier` shape (opaque `Styles` token counting pushed colours/vars, push only non-null, always paired with `popStyles`).
